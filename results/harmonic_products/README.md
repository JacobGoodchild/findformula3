# Products of consecutive harmonic numbers: S_q = sum_{k>=1} H_k H_{k+1} ... H_{k+q} / (k (k+1) ... (k+q))

**Who asked.** W. J. Chen and V. Nguyen, arXiv:2507.19502, state the Furdui-Sintamarian conjecture (S_q is a rational
combination of zeta(2),...,zeta(q+2)), show that the case q=3 contains zeta(2)zeta(3) (so the conjecture "possibly fails"),
and end with: "Perhaps we can learn more by computing the closed form for S_q (q in N)."

**What we did.** An exact algorithm (no numerics) that writes S_q as a rational combination of multiple zeta values (MZVs),
for any q, and the resulting closed forms for q = 1..8 (`S_table.txt`; q=1,2,3 agree with the literature, q>=4 are new as far as we can find).

## Method (this is the proof)
1. Write H_{k+j} = H_k + sum_{i=1}^j 1/(k+i). Expanding the product gives sum_m H_k^m R_m(k), R_m rational with simple/multiple poles at k=0..-q
   and R_m = O(k^-(q+1)), so each block converges.
2. Partial fractions of R_m (exact, `fastpf.py`) give sums  sum_{n>=1} H_n^m/(n+a)^s.
3. Shifted sums are reduced to unshifted ones: put p=n+a, H_{p-a} = H_p -+ (finite sum of 1/(p+i)); this lowers the power of H, so a finite recursion
   ends in sums sum_p 1/(p+b)^u (Hurwitz-type, exact rational heads) -- `reduce_sum` in `exact_reduce.py`. Upper-limit shifts only change terms of size O(log^m K / K).
4. Unshifted sums sum_p H_p^m/p^s are written as nested sums (quasi-shuffle algebra) and stuffle-regularised: divergent pieces become powers of T = H_K.
   All powers of T cancel identically (the code asserts this), leaving a Q-linear combination of MZVs.
5. The MZVs (weights 2..q+2) are converted to products of single zeta values by identities found with PSLQ at 150 digits (`reduce_mzv.py`, `mzv_table.json`).
   For weight <= 7 these are classical theorems (every MZV of weight <= 7 is a polynomial in single zeta values). For weight 8 one needs zeta(5,3) as an extra generator.

## Checks
* `check_exact.py`: the exact MZV combination agrees with direct summation (Euler-Maclaurin, `numerics.py`) to ~1e-62 for q = 1..9.
* `verify.py`: the final zeta-product closed forms agree with the numerics to 45 digits for q = 1..8.
* q=3 reproduces Chen-Nguyen's formula exactly; q=1,2 reproduce Furdui-Sintamarian.

## Results
See `S_table.txt`. Examples:
* S_4 = zeta(2)/432 - 45 zeta(3)/64 + 1799 zeta(2)^2/8640 - 11 zeta(2)zeta(3)/72 + 13 zeta(5)/18 + zeta(2)^3/60 - zeta(3)^2/48
* S_5 = 83 zeta(2)/16200 - 26657 zeta(3)/86400 - 9811 zeta(2)^2/64800 + 347 zeta(2)zeta(3)/43200 + 1669 zeta(5)/2880 + 61633 zeta(2)^3/756000
        - 137 zeta(3)^2/1440 - zeta(2)^2 zeta(3)/300 - zeta(2)zeta(5)/120 + zeta(7)/30
* Observations (q <= 8): S_q lies in the Q-algebra generated by single zeta values for q<=6; zeta(5,3) first shows up at q=7 (weight 8 < top weight 9), and nothing of weight 10 beyond products at q=8.
  So the Furdui-Sintamarian "linear in zeta(2..q+2)" form is false in form for q>=3 unless products of zeta values collapse (zeta(2)zeta(3) in span of zeta(2..5), etc.), which is believed false but unproved.
* Top-weight pattern (observed for odd q = 1,3,5,7, NOT proved): coefficient of zeta(q+2) is (q+3)/(2 q!) and of zeta(2)zeta(q) is -1/q! (q>=3).
